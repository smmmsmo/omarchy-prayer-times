# Security and privacy

Use [GitHub’s private vulnerability report form](https://github.com/smmmsmo/omarchy-prayer-times/security/advisories/new) if enabled, or contact the maintainer privately before publishing any technical details. Do not put locations, `shell.json`, credentials, or cache files in a public issue.

The plugin makes no network requests on a fresh install until you choose **Refresh** or enable automatic fetching. Network destinations, the data sent, and the local cache lifecycle are documented in [the README](README.md#privacy-and-reliability). It does not execute downloaded content. Omarchy plugins run with user permissions. A marketplace compatibility or baseline result is not a security audit or a guarantee.
